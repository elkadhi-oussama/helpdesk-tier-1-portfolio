# Help Desk Tier 1 Portfolio

## About This Project

This repository documents my hands-on Help Desk Tier 1 training through simulated IT support tickets.

I use practical scenarios to develop my skills in user account administration, Active Directory, identity and access management, ticket investigation, troubleshooting, and technical documentation.

## Learning Objectives

- Investigate IT support requests.
- Understand user provisioning and deprovisioning.
- Review account status and group membership.
- Apply least privilege and safe account-management practices.
- Write clear work notes and resolution notes.
- Identify when a ticket should be escalated.
- Validate changes before resolving a ticket.
- Learn from mistakes and improve ticket quality.

## Tools and Technologies

- Active Directory concepts
- User and group administration
- Identity and Access Management (IAM)
- Help Desk ticketing workflows
- Incident documentation
- Troubleshooting and escalation

## Ticket Case Studies

| Case Study | Main Learning Objective |
|---|---|
| New user provisioning | Create an account using the requested attributes |
| Service account review | Assess account activity and dependencies before changes |
| Shared account review | Preserve the account and escalate a policy decision |
| Returning employee | Re-enable an account and reset its password as required |

More case studies will be added as I complete additional training tickets.

## Lessons Learned

- Verify the request before making account changes.
- Do not make unrequested changes to group memberships.
- Escalate policy decisions to the appropriate team.
- Follow all required steps before resolving a ticket.
- Document only actions that were actually completed.
- Validate the final state before closing a ticket.

## Training Disclaimer

This is a personal learning portfolio based on simulated Help Desk scenarios. It is not a collection of real customer incidents or evidence of employment with the training platform.

All case studies are written in my own words and sanitized to protect privacy.
